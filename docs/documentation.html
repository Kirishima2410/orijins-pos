Orijins POS System

A full-stack Point of Sale web application built for Orijins Coffee Shop — serving both customers and staff in one unified platform.

React 18 + TypeScript Node.js + Express MySQL JWT Auth PM2 Deployment
1

Project Overview

Orijins POS is a web-based Point of Sale system developed for Orijins, a local coffee shop. It replaces manual order-taking and cash handling with a digital workflow accessible from any browser — no installation required.

The system serves two distinct user groups on the same platform:

🛒

Customer Portal

Browse the menu, build a cart, and pay via Cash or GCash from any device or at the table via QR code.

🖥️

Staff Dashboard

Full POS, order management, menu control, inventory tracking, reports, and business settings — role-controlled.

📊

Reports & Analytics

Real-time dashboard, sales charts, and downloadable PDF/Excel reports for business decision-making.

📦

Inventory Tracking

Daily manual inventory sheets for raw ingredients — beginning balance, deliveries, usage, waste, and ending balance.

Security

  • JWT AuthenticationSigned tokens expire in 1 hour. No sessions stored server-side.
  • Password Hashingbcryptjs with 10 salt rounds. Plain-text passwords never stored.
  • HTTP Security HeadersHelmet.js sets XSS protection, HSTS, content security policy.
  • Rate Limitingexpress-rate-limit throttles requests per IP in production.
  • Input Validationexpress-validator sanitizes and validates all request bodies.
  • SQL Injection PreventionAll queries use parameterized statements via mysql2.
  • CORS RestrictionAPI only accepts requests from the configured frontend origin.
  • Admin Re-verificationSensitive actions (void order) require re-entering admin password.
  • Audit LoggingEvery create/update/delete is logged with old and new JSON values.

Deployment

The system is deployed using PM2, which manages both the backend Node.js process and the frontend static file server — with auto-restart on crash.

Deployment Flow
flowchart LR A[Clone Repository] --> B[npm run install-all] B --> C[Run schema.sql\nin MySQL Workbench] C --> D[Configure backend/.env\nDB + JWT + CORS] D --> E[cd frontend\nnpm run build] E --> F[pm2 start ecosystem.config.js\n--env production] F --> G1["✅ Backend running\nlocalhost:5000"] F --> G2["✅ Frontend served\nlocalhost:3000"]

# Database

# Auth
